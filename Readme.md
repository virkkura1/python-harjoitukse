Tehtäväaihe: Muuttujat ja vuorovaikutteiset ohjelmat.

1. Käyttäjän nimen kysyminen ja tervehdys (input, print)
2. Ympyrän pinta-ala (math-kirjasto, f-string pyöristyksellä)
3. Suorakulmion pinta-ala ja piiri
4. Kokonaisluvut summa, tulo, keskiarvo

Opitut käsitteet: // ja % -operaattorit, random.randint()  f-stringit merkkijonojen yhdistämiseen numeroista.
